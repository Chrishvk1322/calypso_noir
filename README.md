# Calypso Noir

Tienda virtual de **Calypso Noir**, una marca peruana de piezas hechas a mano en arcilla polimérica: aretes, collares, broches y accesorios organizados por colecciones.

El sitio permite explorar el catálogo, ver el detalle y stock de cada pieza y armar un carrito. La compra se completa por WhatsApp con un código de pedido único (ej. `#PED-8492`) para coordinar el pago, mientras que los pedidos, el stock y el contenido de la tienda se gestionan desde un panel de administración.

Enviamos a todo el Perú.
